# Travel OS V1

Private-first collaborative travel planning and expense tracking built with Next.js App Router, TypeScript, Supabase, React Query, Tailwind CSS, and shadcn-style UI primitives.

## V1 Scope

- Login only
- My Trips
- Trip Overview
- Places
- Expenses
- Create trip
- Invite member
- Complete, archive, restore, soft delete, and restore deleted trip

No signup, settlements, OCR, AI suggestions, currency conversion, live FX, checklist, todos, settings page, or offline/PWA support are included in V1.

## Setup

```bash
corepack pnpm install
corepack pnpm dev
```

Run the Supabase migrations in `supabase/migrations` in order.
